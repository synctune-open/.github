# Synctune Open

Synctune Open is a branch of [Synctune](https://github.com/synctune-io), focused on open-source software for local development and self-hosted infrastructure. We build tools that help people run, inspect, and control their own systems.

## Projects

| Repository | Focus |
| --- | --- |
| [porto](https://github.com/synctune-open/porto) | An orchestrator for local containers, self-hosted apps, and homelabs. |
| [sql-not-so-lite](https://github.com/synctune-open/sql-not-so-lite) | A SQLite manager for local and self-hosted applications. |
| [etcqlite](https://github.com/synctune-open/etcqlite) | An etcd-compatible SQLite storage project. |
| [kill-switch](https://github.com/synctune-open/kill-switch) | A lightweight macOS resource monitor for agentic development. |
| [stainless](https://github.com/synctune-open/stainless) | An unblocked browser. |

Repository links use their planned organization locations. Some may be private or pending transfer.
